## 已确认的技术事实

- 微信文章页可提取账号信息、文章标题、摘要、作者、发布时间、封面、正文 HTML、原文链接和文章类型。
- 公众号官方接口 `freepublish/batchget` 可分页列出已发表文章，但需要该公众号的 AppID/AppSecret、有效 access token、接口权限和正确的 IP 白名单。
- 微信接口即使失败也常返回 HTTP 200，因此必须检查 JSON 中的 `errcode`。
- 官方后台/API只用于只读枚举和读取；本任务不调用发布、群发、删除、改菜单等接口。
- 单靠搜索引擎或公开搜一搜不适合作为“全量”的唯一依据，因为历史收录可能不完整。

## 默认范围假设

- “所有内容”指全部公开发表内容，而非草稿、粉丝数据、私信或后台统计。
- 多图文消息中的每一篇都算独立文章并单独归档。
- 已删除、违规或访问受限的条目若仍能从清单发现，则保留元数据、状态和原始链接，并进入失败/重试报告。

## 技术决策

| 决策 | 理由 |
|---|---|
| 归档根目录为 `content-archive/wechat/阿柑少年/` | 与网站源码分离，名称清晰且便于整体搬运 |
| 输出 JSONL + CSV + Markdown 索引 | 同时满足程序导入、人工检查和内容编辑 |
| 使用稳定文章 ID 命名目录 | 避免同名标题、改标题或特殊字符导致冲突 |
| 图片下载并改写相对路径 | 网站迁移不依赖微信图片防盗链或远程可用性 |
| 浏览器入口受限后不做策略绕过 | 保持采集过程合规；权威替代是官方 API，次优替代是用户提供的公开文章入口 |
