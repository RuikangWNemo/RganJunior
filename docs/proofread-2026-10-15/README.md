## 数据与验证范围

公开故事的中文正文来自数据库，英文来自本地翻译。`articleCorrections.ts` 只对指定故事中已确认的原句进行展示修正，不覆盖整篇数据库文章，不改变署名、发布状态或可见范围。重复应用不会重复附加说明；无关故事、段落和图片结构保持原样。本地文章备份中的明确错字和日期也已同步。

应用、API、后端类型检查通过；全库 Lint 0 错误、9 条既有 Fast Refresh 警告。进一步优化中已修正 `ccba5a7` 对应的旧访问统计断言，确认只展示累计 PV、不会误用会话数；全量 98 个测试文件、376 项测试通过。中文名和英文名提交时移除首尾空格，测试覆盖空白拒绝与规范化保存。

本地 Supabase 连接配置为空。浏览器动态内容检查使用独立临时构建、现有文章目录和身份样本，通过原有读取与展示代码检查响应到页面的行为；不代表真实数据库连接、注册、邮件发送或权限流程已完成端到端验证。浏览器结果保存在 `browser/results.json`，截图在同目录。

已检查 12 个页面 × 中英文 × 1440 / 390 像素，共 48 组页面，页面无横向溢出、无脚本错误；逐一操作三个身份弹窗及注册身份、年龄步骤，没有提交账号。视觉复核额外发现并修复手机端英文首页按钮内溢出，重新运行首页测试、应用类型检查、本地构建和相关页面边界检查。只检查整页滚动宽度不足以证明组件内部没有溢出，因此额外验证按钮子元素边界。

CTB 外链抓取不可用，论文正式题名、卷期取自用户提供的详情截图（列表截图显示不同年度，采用更具体的详情页及用户反馈）。发布阶段不写入生产数据库或修改 OSS，不在共享 ECS 构建。发布与生产复核结果见本目录 release.md。
