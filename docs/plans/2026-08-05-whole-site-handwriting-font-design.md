# 全站手写字体接入设计

## 目标

将用户提供的“悄悄话手写”字体作为网站的全局字体，并确保未来新增的中英文内容仍可直接使用该字体。

## 已确认方案

- 使用字体内部名称为 `hope`、字重为 Light 的完整字体文件。
- 保留完整字符集，不依据当前页面文案做字形子集化。
- 将原始 TTF 转换为 WOFF2，以减少网络传输体积，但不删除任何字形。
- 正文、标题以及 Tailwind 的 `font-sans`、`font-serif` 均优先使用该字体。
- 保留现有 Noto、Inter、Georgia 和系统字体作为加载失败或极少数字符缺失时的后备。
- 代码和数据等明确使用等宽字体的内容继续保持等宽字体，以免降低可读性。

## 实施计划

1. 将完整字体转换并保存到 `public/fonts`。
2. 在全局样式中声明 `@font-face`，并更新正文、标题及显式字体规则。
3. 更新 Tailwind 字体族配置，使工具类与全局样式保持一致。
4. 比较转换前后的字形数量和字符映射，确认没有丢失字形。
5. 运行测试、生产构建并检查构建产物包含字体资源。

## 验收标准

- 全站普通正文和标题均解析到新字体族。
- WOFF2 保留原始字体的完整 glyph set 和 cmap。
- 新增中文不依赖重新生成字体文件。
- 测试和生产构建通过，字体资源可由网站本地路径加载。
