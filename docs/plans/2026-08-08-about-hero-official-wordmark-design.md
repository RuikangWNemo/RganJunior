# 关于页首屏官方文字字标设计

## 目标

将关于页首屏标题第二行的“阿柑少年”从手写字体文字替换为现有官方 Logo 的文字字标，同时保留第一行“关于”的橙色手写体。

## 设计

- 复用现有 `BrandWordmark` SVG，不重新绘制或用字体模拟品牌字形。
- 只显示文字字标，不重复导航栏中的橙色图形标志。
- 中文显示官方“阿柑少年”字标，英文显示官方 `R-Gan Junior` 字标。
- 字标使用品牌橙色，与“关于”保持统一的一级标题色彩，同时以官方 SVG 字形区分品牌字标与手写标题。
- 字标保持第二行位置，宽度随标题字号响应式缩放，避免移动端横向溢出。
- `h1` 保留完整中英文 `aria-label`，SVG 本身作为装饰隐藏，确保标题语义不变。

## 范围

只修改关于页首屏标题及其测试和局部样式，不改动共享字标路径、导航 Logo、其他页面或关于页正文排版。

## 验证

- 中文与英文标题均渲染对应的官方字标 SVG。
- 桌面和手机端字标完整、清晰、无变形和横向溢出。
- 页面主标题仍可通过完整无障碍名称访问。
- 运行关于页测试和生产构建。
