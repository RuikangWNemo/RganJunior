# 四篇成长故事英文版实施计划

## 1. 建立双语正文数据结构

- 将 `VoiceStory.bodyHtml` 调整为中英文内容对象；
- 为四篇成长故事导入独立英文 HTML；
- 为中文项目发起信提供安全的正文回退；
- 在文章页面按全局语言选择正文并设置正确的 `lang` 属性。

## 2. 翻译四篇成长故事

- 按 Nate、若容、若音、天时的顺序完成自然英文叙事润色；
- 保留原文事实、第一人称、章节和强调层级；
- 翻译图片说明、日期说明与图片替代文本；
- 保持所有图片路径、尺寸、顺序和媒体组合类不变。

## 3. 调整文章界面

- 删除英文模式下“仅提供中文正文”的提示；
- 语言切换时同步更新正文语言和全部文章文字；
- 保持项目发起信及现有个人故事编辑排版不变。

## 4. 自动验证

- 覆盖四篇故事的双语正文完整性；
- 验证中英文模式呈现不同正文；
- 验证图片数量和媒体组结构没有变化；
- 运行 Vitest、ESLint 和 Vite 生产构建。

## 5. 页面验收

- 检查四篇英文正文的标题层级、强调和图片说明；
- 检查语言切换不改变 URL 和阅读位置结构；
- 检查桌面与手机布局没有横向溢出或破图。
