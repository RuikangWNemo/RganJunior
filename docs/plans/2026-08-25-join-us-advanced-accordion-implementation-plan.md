# 加入我们：高级折叠信息区实施计划

## 目标

在保留现有 `/join` 编辑封面、种子社群身份路径、角色档案和报名路由的基础上，新增已确认的编辑部目录式折叠信息区，并完成可访问性、双语、响应式与自动化验证。

## 任务 1：确认复用边界与 UI 规范

涉及文件：

- `src/pages/JoinUs.tsx`
- `src/components/ui/accordion.tsx`
- `src/index.css`

步骤：

1. 检查项目现有 Accordion 封装和 Join 页面颜色、字体、按钮、焦点与响应式模式。
2. 通过 UI Skills 选择最小的折叠／信息密度规范。
3. 通过 Better Icons 确认展开、方向和步骤图标；优先复用当前依赖，避免增加新包。
4. 明确新增信息区的 DOM 边界，避免改动现有身份舞台和角色 Dialog。

## 任务 2：先补回归测试

涉及文件：

- `src/pages/JoinUs.test.tsx`

步骤：

1. 断言新的 Ways to Join 标题、核心导语和五个主折叠触发器存在。
2. 断言“当前参与方式”默认展开，并包含四种参与方式。
3. 断言切换到“适合谁”后显示正向与边界内容，并收起前一章节。
4. 断言 FAQ 二级折叠可以打开指定回答。
5. 断言“提交参与意向”进入 `/join/apply`，“预约沟通”定位联系方式。
6. 保留现有身份路径、角色档案和绿色舞台 CTA 断言，证明旧体验未回归。

## 任务 3：建立双语内容模型与折叠结构

涉及文件：

- `src/pages/JoinUs.tsx`

步骤：

1. 为适合／不适合、四种参与方式、四步加入流程、六条 FAQ、联系方式和最终邀请建立类型化双语常量。
2. 增加页面内 `JoinInfoAccordion` 和必要的小型展示组件，避免为静态内容引入全局状态。
3. 使用单选 Accordion，默认值设为参与方式章节，并允许全部关闭。
4. FAQ 使用独立轻量折叠语义，避免主 Accordion 状态相互干扰。
5. 将新增区域插入 Seed Community 舞台之后、角色 Dialog 之前；Dialog 保持页面级 portal 行为不变。
6. 联系信息缺失项显示“待更新 / To be updated”，地点使用真实提供内容。

## 任务 4：完成高级编辑视觉与响应式布局

涉及文件：

- `src/index.css`

步骤：

1. 新增米白信息区、明暗过渡边界、桌面双栏和粘性导语样式。
2. 为编号触发器、摘要、展开线、圆形图标、参与方式行、步骤、FAQ 和联系人列表建立统一编辑样式。
3. 使用现有 Join 变量与字体，不增加第二套颜色或阴影系统。
4. 在 767px 以下切换单栏、移除粘性、调整触控高度和 CTA 排列。
5. 为 `prefers-reduced-motion` 关闭新增位移、旋转与高度过渡。

## 任务 5：聚焦验证与质量复核

步骤：

1. 运行 `npm test -- --run src/pages/JoinUs.test.tsx`。
2. 运行 `npm run typecheck:app`。
3. 运行 `npm run lint`。
4. 运行 `npm run build`。
5. 运行 `git diff --check` 并检查只改动任务相关文件。
6. 如果编辑多个 TSX 组件，运行 React best-practices 复核；若只编辑单个页面组件，则按同等清单人工复核。

## 任务 6：浏览器验证

步骤：

1. 启动本地开发服务器，并按可用工具加载浏览器验证流程。
2. 桌面端检查三段式页面节奏、粘性导语、默认展开、章节切换、FAQ 和 CTA。
3. 390px 移动端检查单列顺序、触控目标、文字换行、按钮堆叠和无横向溢出。
4. 检查控制台错误、React 错误浮层、焦点可见性和减少动态模式。
5. 将截图和验证结果记录到 `progress.md`。
