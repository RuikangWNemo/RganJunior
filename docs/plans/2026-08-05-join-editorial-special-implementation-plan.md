# 加入我们：种子社群编辑特刊实施计划

## 目标

将 `/join` 改造成已确认的高级编辑特刊：淡米色封面、绿色连续身份路径、隐藏式交互、阿柑引导和右侧角色档案折页。独立报名路由与提交接口保持不变。

## 任务 1：建立编辑特刊内容模型

涉及文件：

- `src/pages/JoinUs.tsx`
- `src/content/siteContent.ts`（仅在确有必要时调整）

步骤：

1. 为三个身份补齐刊号、英文短标、短身份暗示和阿柑意图选项。
2. 保持 `joinAudiences` 为详细介绍与报名文案的唯一来源。
3. 保留已暂停的吊牌实现与素材映射，不重新渲染吊牌。

## 任务 2：重建淡米色编辑封面

涉及文件：

- `src/pages/JoinUs.tsx`
- `src/index.css`

步骤：

1. 添加期刊刊头、分行大标题、边注与页码式信息。
2. 使用不对称桌面网格和纵向移动排版。
3. 让橙色编辑线从封面边界视觉延伸到绿色路径。
4. 删除重复说明与无意义装饰。

## 任务 3：重建连续身份路径舞台

涉及文件：

- `src/pages/JoinUs.tsx`
- `src/components/home/SeedCommunityStage.tsx`
- `src/index.css`

步骤：

1. 保留一条完整基础路径，添加可根据当前 hover／focus 身份描亮的局部路径层。
2. 将胶囊按钮替换为编号、身份名称和短暗示组成的编辑节点。
3. 重排桌面与移动节点，使曲线完整、视觉重心均衡。
4. 调整阿柑尺寸和裁切，让它与路径构图而不遮挡内容。
5. 移除当前解释句、普通气泡、大圆线背景和多余空白。

## 任务 4：加入隐藏式阿柑引导

涉及文件：

- `src/pages/JoinUs.tsx`
- `src/index.css`

步骤：

1. 默认只显示小型手写批注入口。
2. hover、focus 或点击后显示一条阿柑提示和三个意图选择。
3. 将三个意图映射到阿柑少年、家长、伙伴，并打开共用角色档案。
4. 使用轻微位移和文字显现；减少动态模式直接呈现稳定状态。

## 任务 5：将角色详情改为编辑档案折页

涉及文件：

- `src/pages/JoinUs.tsx`
- `src/index.css`

步骤：

1. 继续复用现有可访问 Dialog 基础能力。
2. 桌面端改成从右侧进入的半屏档案，移动端改成底部近全屏阅读页。
3. 添加编号、英文短标和三身份快速切换。
4. 保留现有详情行和唯一报名入口，链接继续使用 `/join/apply?audience=<id>`。
5. 保持 Esc、遮罩点击、焦点锁定与关闭按钮行为。

## 任务 6：更新自动化测试

涉及文件：

- `src/pages/JoinUs.test.tsx`

步骤：

1. 更新封面刊头、大标题和连续路径断言。
2. 验证编辑身份节点和隐藏身份暗示。
3. 验证节点打开档案、档案切换与正确报名链接。
4. 验证阿柑引导的三种意图映射。
5. 继续确认吊牌、内联详情和内联表单不会常驻页面。

## 任务 7：完整验证

步骤：

1. 运行 `npm test -- --run src/pages/JoinUs.test.tsx`。
2. 运行完整测试、Lint、生产构建与 `git diff --check`。
3. 在 1440px 桌面与 390px 手机视口实测页面和档案折页。
4. 检查完整曲线、焦点状态、触控目标、横向溢出、错误浮层与控制台错误。
5. 对照首页种子社群，确认配色统一，但加入页面具有更强的编辑层级和独立识别度。
