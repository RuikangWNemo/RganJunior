# 首页 Hero 字标与橙色统一设计

## 目标

缩小首页 Hero 的“阿柑少年”品牌字标，统一 Hero 内的橙色，并优化手机端字标位置与中文标语断行。

## 已确认设计

- “logo”指 Hero 中的“阿柑少年”文字字标，不改变左侧或手机顶部吉祥物的尺寸。
- 字标的桌面与手机宽度统一调整为当前值的 `80%`，通过容器尺寸控制，不使用保留旧占位的视觉缩放。
- 手机端将字标视觉位置向上移动约 `8px`，其他 Hero 内容保持原有布局顺序。
- 中文标语明确分为两行：第一行“回归自然、生活与真实世界，”，第二行“长出内在的力量”。英文断行保持现状。
- Hero 内的字标、主按钮、导航强调、提示气泡、流线暖色节点和吉祥物橙色外观统一到字标当前的 `--home-hero-orange`。
- Hero 以外的首页内容继续使用原有橙色系统，不扩大改色范围。

## 验收

- 桌面字标宽度由 `25.5rem` 调整为 `20.4rem`，手机字标宽度由 `15.5rem` 调整为 `12.4rem`。
- 手机端字标相对当前视觉位置上移约 `8px`，且不引起横向溢出。
- 中文标语在桌面和手机端都稳定显示为指定的两行。
- Hero 可见橙色均以字标橙色为基准，交互状态不跳到另一种橙色色相。
- 英文 Hero 既有字号、断行和内容保持不变。
