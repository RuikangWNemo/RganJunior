# 首页项目板块配色协调设计

## 目标

保持现有 48px / 36px / 18px 三级字体结构与固定卡片布局，通过亮度、色温和强调色职责重新建立和谐的信息层级。

## 已确认方案

- 第一级“我们的项目”继续使用 48px 品牌橙色手写体，作为板块唯一的大面积橙色文字。
- 第二级项目名称使用 36px 暖米白手写体，避免与板块主标题争夺注意力。
- 第三级时长与简介均为 18px 普通字体：时长使用现有浅桃 token，简介使用 78% 米白。
- 顶部“查看我们的项目”使用 76% 米白，悬停和聚焦时转为浅桃色。
- “查看项目详情”由橙色实底改为轻透明米白底、米白描边和米白文字；悬停时使用米白实底与深绿文字。
- 橙色继续用于板块主标题、当前进度线和交互反馈，不作为正文色反复出现。
- 固定卡片取消外部阴影，略微减小圆角并降低内层深绿色强度，以色面、细边框和留白替代悬浮卡片感。
- 不增加新色值，全部复用 `--home-orange`、`--home-orange-soft`、`--home-paper`、`--home-forest` 和 `--home-forest-deep`。

## 可访问性与验证

- 18px 信息文字在绿色背景上保持清晰对比；小字号交互文字不使用品牌橙色作为默认色。
- 保留按钮、进度线和链接的可见聚焦状态，颜色不是唯一的选中信号。
- 运行首页测试、生产构建，并在桌面和移动视口检查明暗层级、按钮状态与照片主次关系。
