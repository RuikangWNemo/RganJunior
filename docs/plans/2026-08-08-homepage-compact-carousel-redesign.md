# 首页单屏叙事与轮播改版设计

## 目标

保留首页 Hero、发起人故事与种子社群入口的现有内容和设计，只重组中间三个板块。桌面端每个板块控制在约一个视口内，移动端保持自然纵向阅读高度。

## 页面顺序

1. Hero（保持不变）
2. 真实现场
3. 我们相信什么
4. 我们的项目
5. 一个少年的成长（保持不变）
6. 成为阿柑少年、家长或伙伴（保持不变）

## 真实现场

- 上方使用横向满宽纪实照片轮播，呈现孩子、自然、厨房、茶席、作品等现场。
- 支持自动切换、左右按钮、触控拖拽与键盘操作。
- 下方集中展示“最近，我们一起生活了五天。”、11 个孩子、9 个家庭、5 天 4 夜及活动叙述。
- 桌面端压缩图片与文字的纵向占用，移动端按图片、标题、数据、正文自然排列。

## 我们相信什么

- 使用左侧单张真实成长照片、右侧三条信念的固定左右结构。
- 三条信念同时可见，不做隐藏切换。
- 编号和标题使用橙色强调，正文使用森林绿；板块使用项目页色块体系中的浅橙底。

## 我们的项目

- 四个项目共用一个左文右图展示框架，通过顶部项目导航依次切换。
- 支持自动切换、项目导航点击、左右按钮、触控拖拽与键盘操作。
- 当前项目可以直接进入详情，同时保留“查看我们的项目”总入口。
- 四个项目统一使用森林绿背景，与浅橙色信念区形成清晰板块区分。
- 项目使用渐显渐隐切换，左右切换按钮放在内容两侧。

## 动效与可访问性

- 真实现场和项目区共用同一套渐显渐隐、滑动与自动播放组件。
- 轮播在鼠标悬停、元素聚焦和页面不可见时暂停。
- 用户开启 `prefers-reduced-motion` 时禁用自动播放与非必要过渡。
- 所有控制按钮提供可访问名称、当前状态和键盘焦点样式。
- 图片保留描述性替代文本与明确尺寸，避免布局跳动。

## 验证

- 更新首页内容顺序、链接和轮播交互测试。
- 运行首页测试、应用类型检查与生产构建。
- 在桌面和移动视口检查单屏高度、溢出、触控滑动、自动切换和中英文布局。
