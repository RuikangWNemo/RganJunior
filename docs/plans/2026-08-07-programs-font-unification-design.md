# 项目页面字体统一设计

## 目标

让项目总览和三个项目详情页完整使用网站现有的手写字体体系，恢复与首页、关于页和其他页面一致的品牌气质。

## 字体规则

- 页面标题、项目标题、章节标题和 FAQ 问题继续使用现有 `font-serif` 角色，对应网站的手写衬线字体栈。
- 正文、滚动菜单、辅助文字、按钮和 FAQ 答案继承网站全局正文设置，对应手写无衬线字体栈。
- 删除项目页面专属的 Noto Sans SC、PingFang SC 和 Microsoft YaHei 字体覆盖。
- 不增加新的字体文件、字体请求或第三方依赖。

## 不变范围

本次不调整以下内容：

- 项目总览版式
- Nate 引言结构与文案
- 三个项目入口的尺寸、顺序和图片
- 滚动定位菜单
- 三个详情页结构
- FAQ 内容与折叠交互
- 间距、颜色、圆角和动画
- 路由、SEO、申请与联系方式

## 验证

- 项目页根节点不再覆盖全站字体。
- 标题计算字体回到网站手写衬线字体栈。
- 正文计算字体回到网站手写无衬线字体栈。
- 页面布局尺寸和功能测试保持不变。
- 运行相关测试、Lint、TypeScript、生产构建和桌面与手机浏览器检查。
