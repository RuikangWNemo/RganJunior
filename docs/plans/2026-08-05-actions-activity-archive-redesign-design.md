# 行动页活动档案改版设计

## 目标

把 `/actions` 从重复解释行动理念的展示页，改成记录真实活动的活动档案。页面重点是发生过什么、何时发生、现场是什么样，而不是抽象概念和成果包装。

## 页面结构

1. 简短页头
   - 只保留“行动 / 我们做过的事”一类明确标题。
   - 用一句话说明以下内容均为真实活动记录。

2. 活动档案
   - 按时间倒序排列已有活动。
   - 每项活动展示日期、活动名称、一句事实说明和现场照片。
   - 有多张照片的活动使用克制的图片组合，不做轮播、悬浮特效或装饰性图形。

3. 页面收束
   - 活动列表结束即结束页面。
   - 删除成果数字、概念总结和加入行动的营销入口。

## 内容原则

- 只使用项目资料中已有时间、名称、事实和照片。
- 删除“恢复感知”“形成行动”等抽象、模板化表达。
- 不夸大影响，不补写未经资料支持的参与人数、地点或成果。
- 保留中英文切换；英文同样使用简短事实描述。

## 视觉原则

- 沿用当前网站的纸张色背景、衬线标题、细分隔线和自然色系。
- 让真实照片成为视觉主体，文字保持短、准、易扫读。
- 桌面端采用清晰的档案行布局，移动端自然堆叠。
- 动效只保留网站已有的轻微页面进入和图片缩放反馈。

## 删除范围

- 大幅概念首屏。
- “三条行动线”总览卡片。
- “感知 / 研究 / 行动”三段理念说明。
- “行动痕迹”成果数字。
- 页面底部“进入行动网络”入口。

## 验证

- 检查中英文内容完整。
- 检查桌面与移动端的照片裁切、文字换行和页面节奏。
- 运行现有测试和生产构建。
