# Impact / 影响公共前端设计

日期：2026-08-07

## 目标

在官网“田野笔记”之后新增“Impact / 影响”一级入口，先完成可上线、可响应式浏览的公共前端。页面不使用虚构案例或虚构统计；当前阶段以结构、视觉和数据契约为主，只展示仓库中已有来源可核验的事实。数据库与社群页面完成后，通过同一数据契约接入真实的活动、参与者与授权成长记录。

## 信息架构

```text
官网导航
├── 发起人故事
├── 田野笔记
└── Impact / 影响
    ├── 统计      /impact
    └── 获奖情况  /impact/awards
```

桌面端使用与“关于”“项目”一致的下拉菜单；移动端在抽屉中展开两个子项。Impact 位于田野笔记之后、加入我们之前。

## 数据原则

- 不展示虚构数字、虚构人物、虚构引语或合成的前后变化。
- 当前可使用的事实包括：28 名同学及家长参与、从 2000+ 支队伍进入 CTB 前 72 名／全球前 3.6%、YSA Journal 发表、Claremont 论坛，以及仓库内对应的真实资料图。
- 活动总数、独立孩子数、独立家庭数、年龄分布、城市来源和家长反馈在缺少可靠记录时不显示数值，也不以 0 或占位数替代。
- 页面数据通过 `ImpactRepository` 形状读取。当前 provider 只返回已核验的本地证据；数据库完成后切换为 Supabase provider，页面组件和路由保持不变。
- 私密成长档案不能直接成为公共页面数据。公开个体变化必须有单独的公开授权、去敏规则和可撤回机制。

## A. 统计页

统计页采用“影响不是结论，而是持续记录”的证据叙事，而不是常规后台仪表盘。

1. 首屏：栏目名、简短说明、真实现场主图，以及最近核验日期。
2. 证据数字：只渲染有来源的数据；每项包含时间或口径说明。
3. 关系图：以少年为中心，连接家庭、伙伴、土地与公共行动。图示表达影响发生的关系结构，不用虚构人物头像填充节点。
4. 成长记录框架：并列呈现“孩子的变化”和“家长的变化”两条观察线。当前展示可记录的维度和真实行动过程；取得授权后可加入参与时间、前后照片和阶段记录。
5. 小行动：使用现有资料中可确认的果园实践、社区清洁、研究发表、校园 CSA 等行动类型。
6. 三个月行动：展示已确定的项目机制——线上相遇、个人或家庭实践、阶段分享——不伪装成尚未确认的具体日历。
7. 数据说明：明确统计范围、更新日期和隐私边界。

## B. 获奖情况页

获奖情况延续网站的纸张底色、森林绿、衬线标题、细分隔线和真实资料照片，采用编辑型时间档案，而不是奖杯卡片墙。

记录按类型区分：

- 竞赛：CTB 全球青年研究创新论坛，2000+ 队伍、前 72 名／前 3.6%。
- 发表：YSA Journal 论文发表。
- 论坛：Claremont 生态文明论坛。
- 实践：Campus CSA 等后续可验证行动成果。

未来媒体报道可沿用同一记录模型增加 `media` 类型，成为 Impact 的次级内容，而不需要重做页面。

## 组件与数据边界

主要组件：

- `ImpactHero`：栏目标题、说明、主图和更新时间。
- `ImpactMetricLedger`：来源明确的宏观数字。
- `RelationshipMap`：少年、家庭、伙伴、土地、公共行动之间的关系图。
- `GrowthTracks`：孩子与家长的双线成长记录框架。
- `ActionFootprints`：孩子带走的小行动。
- `ThreeMonthRhythm`：三个月持续行动机制。
- `ImpactEvidenceList`：竞赛、发表、论坛和媒体记录。

数据项保留 `sourceLabel`、`sourcePath`、`observedAt`、`verifiedAt` 和 `visibility` 等元信息，避免脱离来源的孤立数字。

## 状态、隐私与降级

- 无可核验指标时隐藏该指标，不用假数据填满版面。
- 图片缺失时使用文字档案编号与类型标签，不引入图库人物照。
- 数据请求失败时保留页面结构并显示克制的重试提示。
- 所有个人照片、姓名、加入时间和成长描述默认不公开；只有明确授权的公开记录才进入 public provider。
- 年龄只公开聚合区间；城市只公开足够大的聚合，避免未成年人被间接识别。

## 响应式与无障碍

- 关系图在桌面端为横向网络，在移动端转换为可读的纵向关系链，不依赖横向拖动。
- 图形信息同时以文本结构表达，颜色不是唯一编码。
- 数字包含完整可读标签和口径说明，屏幕阅读器不会只读出孤立数值。
- 动画只用于关系线与内容进入；`prefers-reduced-motion` 下使用静态呈现。
- 导航、子菜单和页面内链接保留键盘焦点与不少于 44px 的触控目标。

## 验证

- 测试导航顺序、Impact 子菜单、统计与获奖路由。
- 测试只渲染有来源的数据，缺失数据不会显示为 0 或演示值。
- 测试中英文文案、关系图文本替代、移动端纵向结构和 reduced motion。
- 运行类型检查、测试、Lint、生产构建，并在桌面与移动尺寸进行浏览器验收。
