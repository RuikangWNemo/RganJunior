# 静态 WebP 优化

用户已选定：先使用 WebP，保持 Vercel 免费部署，不使用阿里云。

方案：在本机显式生成静态 WebP（不放进应用 build 钩子），保留原图；用内容哈希文件名避免旧缓存。统一图片组件根据已生成的清单选择 640/1280/1920 候选，保留现有 srcset、裁切、alt、加载优先级。文章正文只替换已确认存在的本地图片，不修改数据库或外部鉴权链接。照片有损压缩，含文字图表采用无损编码。

替代方案：仅转换几个最大文件，改动少但遗漏其他页面；动态图片处理会增加服务配置和用量，本轮采用预生成文件。原布局保持不变。

验收：检查候选文件实际存在、尺寸不放大、格式正确；验证文章图片优化、外部链接保持原样；运行本地 lint、类型检查、测试和生产构建，并抽查桌面/手机。发布只使用本地验证的预构建产物；工作区其他变更不自动包含在本次发布中。
