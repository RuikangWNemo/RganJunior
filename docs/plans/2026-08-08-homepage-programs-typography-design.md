# 首页“我们的项目”字体层级设计

## 目标

删除首页项目板块中的“阿柑少年可以如何参与”，让“我们的项目”成为板块主标题，并在现有森林绿轮播中建立明确的四级字体系统。

## 已确认方案

- 第一级：“我们的项目”，桌面端 48px、手写体、橙色，使用二级标题语义。
- 第二级：当前项目名称，桌面端 36px、手写体、暖米白色。
- 第三级：项目时长和项目说明，18px、普通字体；时长使用浅桃色，说明使用 78% 米白色。
- 删除四项文字导航及 `01–04` 编号，使用卡片下方的四段进度线切换项目。
- 删除左右切换箭头；保留自动切换、进度线点击、触控滑动和键盘方向键。
- 中英文同步删除“阿柑少年可以如何参与 / How to take part in R-Gan Junior”，英文主标题保留“Our programmes”。
- 保留现有森林绿背景、轮播、图片、导航与链接，不添加新内容或装饰。
- 移动端两档手写标题自适应缩小，两档 18px 普通文字保持可读字号。

## 验证

- 更新首页中英文标题测试，确认“我们的项目”是 H2，旧标题不存在。
- 运行首页定向测试、应用类型检查和生产构建。
- 检查桌面端和移动端的字号、颜色、换行与溢出。
