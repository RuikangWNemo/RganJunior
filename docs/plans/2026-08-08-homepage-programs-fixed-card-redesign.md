# 首页项目固定卡片改版设计

## 目标

减轻首页项目板块的背景重量，消除不同项目文案长度导致的视觉跳动，并让切换方式与“最近，我们一起生活了5天4夜”板块保持一致。

## 已确认方案

- 板块背景从 `--home-forest-deep` 调整为稍浅的 `--home-forest`。
- 使用带轻微透明层、细描边和圆角的固定图文卡片；桌面左文右图，移动端上图下文。
- 文案区为项目名称和简介预留稳定高度，使时长、标题、说明和详情入口在切换时保持相对固定位置。
- “我们的项目”为 48px 橙色手写体；项目名称为 36px 暖米白手写体；时长为 18px 浅桃色普通字体，简介为 18px、78% 米白普通字体。
- 详情按钮使用低调的米白描边与轻透明底，悬停后转为米白实底；卡片取消悬浮阴影，依靠色面、细边框和留白建立层级。
- 删除四项文字导航、`01–04` 编号和左右箭头。
- 卡片下方使用四段同宽进度线；当前项目为橙色实线，其余为半透明白线。
- 保留自动切换、进度线点击、触控滑动、键盘方向键以及悬停/聚焦暂停。
- 切换仅动画 `opacity` 和小幅纵向 `transform`，不动画宽高；离开视口时暂停自动播放。
- `prefers-reduced-motion` 下取消位移与渐变。

## 验证

- 更新首页测试，确认四个进度线按钮可切换内容且左右箭头不存在。
- 运行首页定向测试、应用类型检查和生产构建。
- 在桌面与 390px 移动视口检查背景、卡片高度、文案位置、溢出和切换过程。
