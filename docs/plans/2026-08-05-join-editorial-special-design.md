# 加入我们：种子社群编辑特刊设计

## 目标

将 `/join` 从放大的导航组件重构为一张高级、克制的“种子社群编辑特刊”。页面延续首页的淡米色、阿柑绿与阿柑橙，但建立更强的编辑排版、连续叙事和空间关系。趣味不直接堆在画面上，而是在 hover、键盘聚焦和点击后显现。

报名继续使用独立的 `/join/apply?audience=...` 页面。本次不把表单嵌入 `/join`，也不修改现有提交接口。

## 选择的方向

采用“高级编辑感 70% + 隐藏趣味 30%”的种子社群编辑特刊。

未采用的方向：

- 社群展览导览图：空间与互动更强，但会削弱与首页一致的编辑气质。
- 成长档案馆：足够克制，但阿柑与完整身份路径会退居次要，趣味不足。
- 同页直接填写表单：用户已明确推翻该方向，报名流程继续保持独立。

## 页面构图

页面保留“淡米色封面 → 绿色社群内页”两幕，但要像同一本特刊连续翻页，而不是两个松散区块。

### 淡米色封面

- 使用不对称编辑排版。
- 左上放置小型刊头：`SEED COMMUNITY / JOIN ISSUE 01`。
- 主标题放大并分行：`成为阿柑少年、` / `家长或伙伴。`。
- 右侧只保留窄幅编辑注释或期号，不堆叠说明文字。
- 一条细橙线从封面底部开始，并在视觉上延伸进绿色区域。

### 绿色社群内页

- 橙色曲线作为唯一主路径，完整连接阿柑少年、家长和伙伴。
- 删除“选择一条路，或点点阿柑”等解释性文字。
- 三种身份不再使用胶囊按钮，改为沿曲线排布的大字节点，并配极淡的 `01 / 02 / 03` 编辑编号。
- 阿柑从右下边缘进入，与路径形成构图关系；控制比例，避免吞没内容。
- 默认只呈现身份名称与路径，保持安静和留白。

### 移动端

- 重排为纵向编辑海报：封面标题、纵向曲线、三个大字身份、底部探入的阿柑。
- 不出现长距离空白，不让阿柑遮挡身份节点或交互内容。
- 维持完整连续曲线，不把身份拆成互不相连的卡片。

## 隐藏交互

### 身份节点

- hover 或键盘聚焦时，仅重新描亮节点附近的一小段橙色路径。
- 淡色编号变清晰，身份名称旁滑出一句短身份暗示。
- 手机端首次点击获得同等信息，后续操作可打开详情。
- 不使用大面积发光、彩色卡片或弹跳动画。

### 角色档案折页

- 点击身份后打开对应的“人物档案内页”。
- 桌面端从右侧进入并占约半屏，左侧绿色舞台仍可见。
- 手机端从底部进入，成为接近全屏的阅读页。
- 顶部使用 `01 / YOUTH` 一类编辑编号，随后呈现“适合什么样的人”、现有介绍和唯一报名入口。
- 档案页提供三种身份的直接切换，不要求关闭后重新选择。

### 阿柑

- 默认不展示传统聊天气泡，只留一条小型手写批注：“还不知道选谁？问问我”。
- hover、键盘聚焦或点击后才显示一条随机提示。
- “帮我选”提供三个克制的意图选项：想走进真实世界、正在陪伴孩子、希望以资源或能力共创。
- 选择后进入对应角色档案，与身份节点共用同一内容与状态流。
- 不使用循环漂浮、闪光或持续弹跳。

## 视觉语言

- 淡米色 `#F5F1EB`：封面、档案折页和阅读内容。
- 阿柑绿 `#006644`：身份路径舞台。
- 阿柑橙 `#FF6A1F`：曲线、编号强调与唯一行动入口。
- 深灰黑：标题与正文，避免生硬纯黑。
- 手写字体只用于主标题与阿柑批注。
- 身份名称采用克制的大字号编辑排版，正文使用现有易读字体。
- 使用细线、编号、页码与边注建立杂志感。
- 不使用玻璃卡片、渐变光晕、层叠阴影或胶囊按钮。

## 删除范围

从当前绿色场景移除：

- 解释性引导句。
- 三个深绿色胶囊身份按钮。
- 普通聊天气泡造型。
- 与内容无关的大圆线背景装饰。
- 过大的绿色空白与过度放大的阿柑比例。
- 居中弹窗式详情外观。

全局导航和页脚继续作为网站框架保留，不在页面内部重复品牌信息。此前已暂停的吊牌继续保持不渲染，其实现与素材仍保留以便恢复。

## 组件与状态

- `joinAudiences` 继续作为角色标题、描述、详情行和报名文案的唯一来源。
- 页面拆分为编辑特刊封面、身份路径舞台和角色档案折页三个清晰部分。
- `/join` 管理当前身份、档案开关、阿柑提示和“帮我选”状态。
- 点击身份和通过阿柑选择身份进入同一档案状态，不复制内容。
- 未知身份值安全回退到阿柑少年。
- 报名链接保持 `/join/apply?audience=<identity-id>`。

## 可访问性与动态

- 身份节点使用语义按钮并保留清晰的键盘焦点状态。
- hover 信息也必须通过键盘聚焦和手机点击获得。
- 档案折页复用可访问的 Dialog 基础能力，包括焦点锁定、Esc 关闭和语义标题。
- 动画限于路径描绘、文字显现与轻微位移。
- `prefers-reduced-motion` 直接显示最终状态，并停止非必要提示轮换。

## 验证

- 确认三个身份位于同一条完整曲线上。
- 确认 hover、键盘和触控均可看到身份暗示。
- 确认角色档案可以打开、切换、关闭，并进入正确的报名地址。
- 确认阿柑“帮我选”正确匹配三种身份。
- 验证中英文、减少动态模式、桌面与手机布局。
- 检查没有横向溢出、错误浮层、控制台错误或被阿柑遮挡的文字。
- 运行页面测试、完整测试、Lint 与生产构建。
