# 阿柑少年社群中枢体验重设计实施计划

日期：2026-08-08
依据：`docs/plans/2026-08-08-community-experience-redesign-design.md`

## 实施边界

- 保留现有 Supabase Auth、社群状态解析、年龄分流、监护人确认、申请审核、成员资格与权限守卫。
- 不增加 migration，不修改远端数据，不自动翻译用户生成内容。
- 只在 community 路由、社区组件、社区页面及必要的 Layout 路由壳层内工作。
- 工作树已有大量用户改动；修改前检查重叠，提交和暂存只包含本任务文件。

## 1. 建立可测试的社区语言与导航基础

新增集中式社区 UI 文案资源：

- 通过现有 `LanguageContext` 读取 `zh | en`。
- 覆盖全局壳层、主导航、页面头部、状态、加载、空状态、错误、操作与流程步骤。
- 提供状态本地化和日期时间格式化 helper。

新增社区路由元数据：

- 为社区首页、文章、编辑器、伙伴、共练、消息、设置、流程页和管理页定义栏目、面包屑与稳定上级。
- 对动态文章编辑路由提供模式匹配。
- 纯函数测试覆盖中英文标签和主要深层路由的返回目标。

## 2. 统一 CommunityChrome

新增全局社区壳层并接入 `Layout` 的 community 分支：

- 顶栏品牌入口指向 `/community/enter`。
- 官网入口指向 `/`。
- 提供中 / EN 切换。
- 已登录用户提供设置、按权限显示的管理入口和退出操作。
- 移动端显示当前栏目与稳定返回按钮。
- 为固定顶栏、安全区、主内容和 reduced-motion 建立统一样式。

移除 `CommunityAuth` 内重复的独立品牌栏，认证表单保留现有逻辑并适配新壳层。

新增组件测试验证品牌、官网、语言和条件账号入口。

## 3. 重构 CommunityShell 与 CommunitySurface

`CommunityShell`：

- 桌面侧栏保持六个成员区域，并增加权限控制的管理快捷入口。
- 移动底栏只保留五个高频区域，显示图标与文字；设置由顶栏账号菜单到达。
- 加入更清楚的 active、hover、focus-visible 和 reduced-motion 状态。

`CommunitySurface`：

- 支持面包屑、稳定返回、标题区主要动作、辅助区域和宽度变体。
- 提供共享的 Loading、Empty、Error/Retry 和 Notice 视觉组件。
- 调整表单与按钮样式，建立统一状态反馈。

将正式成员的设置路由纳入成员壳层；非成员仍由现有状态守卫进入正确流程。

## 4. 重做成员首页和核心内容页

### 首页

- 使用欢迎区、通知区和四个主要行动卡建立仪表盘层级。
- 完整本地化账号上下文、通知内容选择和空状态。
- 通知读取失败显示重试，不再伪装成空列表。

### 伙伴

- 强化自然名、展示名、双语姓名、地点和简介层级。
- 区分加载、空结果、读取失败、本人和发起消息失败。
- 保留现有会话创建与跳转逻辑。

### 文章与编辑器

- 文章列表显示本地化审核状态、可见范围、更新时间和明确编辑入口。
- 新建/编辑页增加面包屑、返回文章、保存中/成功/失败状态。
- 保留现有 Field Notes service 和审核状态流转。

### 共练

- 使用本地化日期时间、席位进度和参与状态。
- 为加入、取消、候补、会议信息与创建表单提供即时反馈。
- 保留权限控制与 service 调用。

### 消息

- 桌面建立会话/内容双栏；移动端建立列表/会话的稳定返回。
- 本地化空会话、发送中、发送失败与不可用状态。
- 保留查询参数选择会话的现有行为。

### 设置

- 按个人资料、隐私和账号分区。
- 本地化表单、帮助文字和保存反馈。
- 保留资料 service、密码修改和退出逻辑。

## 5. 统一认证与入群流程

在不改认证逻辑的前提下本地化并统一：

- 登录 / 注册 / Magic Link / 找回密码。
- 资料完善。
- 社群申请。
- 监护人邀请与确认。
- 申请状态。
- 密码重置与认证回调状态。

增加统一流程步骤组件，按当前年龄和状态显示适用步骤。所有流程页提供稳定返回或退出至官网的路径。

## 6. 统一管理页面

- 申请审核和举报管理使用全局社区顶栏、面包屑和稳定返回。
- 本地化页面结构、操作与状态，但不改变敏感字段、权限校验和审核 service。
- 保持无权限用户由现有守卫返回成员首页。

## 7. 视觉系统与响应式完善

在社区范围内建立“营地中的社群中枢”视觉变量和组件样式：

- 暖米白背景、森林绿结构、柑橘橙行动色。
- 轻微颗粒、有机背景色块和克制的编辑式排版。
- 卡片悬浮、箭头位移、短距离页面进入和清晰 focus-visible。
- `prefers-reduced-motion` 禁用非必要位移。
- 390px 手机宽度验证顶栏、底栏、安全区、表单和消息布局。

## 8. 验证

1. 运行社区导航、壳层、语言和更新页面的聚焦测试。
2. 运行 `npm run typecheck:app`。
3. 运行相关文件 ESLint；记录并区分既有问题。
4. 运行完整 `npm test`。
5. 运行 `npm run build`。
6. 启动本地站点，在约 1440px 桌面与 390px 手机宽度走查认证入口、流程页、成员首页和各次级页面。
7. 核对 `git diff`，确认没有 migration、远端数据或无关文件改动。
