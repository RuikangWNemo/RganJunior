# 四篇个人成长故事编辑排版实施计划

## 1. 建立故事页面变体

- 在 `VoiceArticle` 根据 `story.kind` 添加成长故事专属根类；
- 重组标题区、封面区、正文入口和阅读收束的语义类；
- 保持项目发起信的现有结构和样式路径。

## 2. 标注媒体语义

- 扩展微信文章导入脚本，根据图片宽高标注横图、竖图和近方图；
- 识别连续纯图片块并包装为媒体组；
- 不改变图片顺序、正文文字和图注内容；
- 对四份现有成长故事 HTML 执行同一机械规范化。

## 3. 实现编辑排版

- 将正文文字列与媒体列分离；
- 设定横图、单张竖图、连续竖图及混合图片组的响应式规则；
- 统一章节标题、段落、图注、封面与结尾推荐的层级和间距；
- 明确 390px 手机端与桌面端的折叠和宽度规则。

## 4. 自动验证

- 为成长故事变体和项目发起信隔离补充组件测试；
- 为媒体方向与图片组标注补充导入脚本测试；
- 运行 Vitest、ESLint 和 Vite 生产构建。

## 5. 浏览器验收

- 在 390px 视口逐篇检查四篇成长故事；
- 在桌面视口检查文字列、媒体突破宽度和阅读收束；
- 确认项目发起信没有套用成长故事排版；
- 检查横向溢出、控制台错误、破图与照片顺序。
