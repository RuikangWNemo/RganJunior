# 伙伴星球广场实施计划

日期：2026-08-08  
依据：`docs/plans/2026-08-08-community-people-planet-design.md`

## 实施边界

- 只修改伙伴页、伙伴星球组件、必要的 Community 样式和测试。
- 复用现有人员目录与私聊服务，不新增 migration、不修改远端数据。
- 星轨仅为视觉结构，不建立或推断成员关系。

## 1. 建立确定性的星球模型

- 新增纯函数模块，用 Fibonacci sphere 将成员稳定分布到球面。
- 新增视觉星轨生成函数，限制线段数量并保证同一输入输出稳定。
- 添加位置半径、唯一性和确定性测试。

## 2. 构建延迟加载的 3D 星球

- 新增 React Three Fiber 场景、透明球体、经纬纹理、星点与弧线。
- 实现拖拽 quaternion、惯性、自转、暂停与重置。
- 实现选中伙伴后转向镜头前方的 quaternion 插值。
- 控制 DPR、离屏运行和 reduced-motion。

## 3. 重构伙伴页交互层

- 增加星球/名单切换、旋转控制和星轨说明。
- 增加桌面侧边资料面板、移动资料卡和伙伴 DOM 索引。
- 保留现有列表资料、本人状态、错误/空状态和消息创建逻辑。
- 为 3D 模块添加 Suspense 骨架与失败降级。

## 4. 视觉与响应式

- 添加 Community 品牌色的星球舞台、控制条、资料面板、索引与列表样式。
- 验证桌面、平板和手机布局，不劫持滚动、不产生横向溢出。
- reduced-motion 下关闭自动旋转与非必要过渡。

## 5. 测试与验证

- 添加星球模型单元测试和伙伴页交互测试。
- 运行 Community 聚焦测试、完整测试、针对性 ESLint、类型检查和生产构建。
- 启动本地站点完成桌面、手机和减少动态效果浏览器验证。
