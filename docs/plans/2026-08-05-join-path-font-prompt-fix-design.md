# 加入我们：字体、曲线与常驻提示修复

## 目标

修复 `/join` 三个身份名称字体未稳定加载、橙色路径视觉断裂，以及阿柑自动提示被隐藏在交互面板中的问题。

## 确认方案

### 身份字体

- 阿柑少年、家长、伙伴改用项目内置字体变量。
- 不再直接依赖需要联网加载的 `Noto Sans SC`。
- 保留现有字号、位置、焦点与 hover 交互。

### 完整曲线

- 基础橙色曲线始终以清晰、统一的颜色完整显示。
- hover／focus 的分段描亮只能增加局部强调，不能让其余路径显得缺失。
- 桌面和移动端均保持一条连续路径。

### 常驻提示

- 自动轮换提示从隐藏面板中分离，常驻在阿柑旁边。
- 提示在页面可见时持续轮换；打开角色档案时暂停。
- 减少动态模式下保持一条稳定提示。
- 删除 `R’GAN’S MARGIN NOTE`。
- “还不知道选谁？问问我”继续作为身份意图选择的展开入口。
- 展开面板只保留“此刻的你，更像——”和三个意图选项。

## 验证

- 检查身份名称的计算字体来自本地字体栈。
- 检查基础曲线完整存在并保持高可见度。
- 检查自动提示默认可见、持续轮换，并在档案打开时暂停。
- 检查展开面板中不再存在 `R’GAN’S MARGIN NOTE` 或重复提示。
- 运行页面测试、完整测试、Lint、生产构建与桌面／手机浏览器检查。
