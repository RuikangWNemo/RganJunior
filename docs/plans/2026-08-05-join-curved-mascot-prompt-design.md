# 加入我们：阿柑轮廓弧形提示设计

## 目标

让常驻自动提示更贴近阿柑，并沿吉祥物外轮廓形成有弧度的排版，而不是作为独立横排文字悬在绿色区域中。

## 确认方案

- 使用 SVG `textPath` 承载自动轮换提示。
- 文字沿阿柑左肩至头顶外缘排列，不覆盖脸部。
- 桌面端使用较长的柔和弧线；手机端使用更浅、更短的弧线保证可读性。
- 弧线路径本身不可见，只显示文字。
- “还不知道选谁？问问我”保留在弧线末端附近，继续展开身份选择面板。
- 自动轮换、角色档案打开时暂停、减少动态模式稳定显示的行为保持不变。

## 可访问性

- SVG 弧形文字作为视觉表现，不重复暴露给屏幕阅读器。
- 保留独立的 `role="status"` 与 `aria-live="polite"` 文本作为无障碍提示来源。
- 入口按钮继续提供清晰的 `aria-expanded` 与 `aria-controls`。

## 验证

- 确认弧形文字贴近阿柑但不覆盖脸部。
- 确认中英文长短文案均不会溢出或被裁切。
- 确认手机端弧线可读，且不与“伙伴”节点或身份曲线重叠。
- 确认身份选择面板仍可完整展开。
- 运行页面测试、完整测试、Lint、生产构建与桌面／手机浏览器检查。
