# 首页“我们相信什么”字体层级设计

## 目标

删除首页信念板块中的“身体力行”，让“我们相信什么”成为板块主标题，并仿照“最近，我们一起生活了5天4夜”板块建立清晰的三级字体系统。

## 已确认方案

- 第一级：“我们相信什么”，桌面端 48px、手写体、橙色，使用二级标题语义。
- 第二级：三条信念标题，桌面端 36px、手写体、橙色。
- 第三级：`01/02/03` 编号和信念说明，18px、普通字体；颜色沿用“5天4夜”板块的 `--home-forest-deep`，编号使用 62% 不透明度，说明使用 74% 不透明度。
- 中英文同步删除“身体力行 / Learning by living”，英文主标题保留“What we believe”。
- 保留现有左图右文、三条信念、分隔线和浅橙背景，不添加新内容或装饰。
- 移动端标题自适应缩小，正文维持 18px，避免长标题溢出。

## 验证

- 更新首页标题测试，确认“我们相信什么”是 H2 且“身体力行”不存在。
- 运行首页定向测试、应用类型检查和生产构建。
- 检查桌面端和移动端的字号层级、换行和中英文布局。
