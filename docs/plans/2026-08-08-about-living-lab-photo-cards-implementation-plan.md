# 关于页真实场域照片卡片实施计划

## 1. 准备站内图片

- 将三张用户照片转换为适合网页加载的 WebP 资源。
- 使用语义化文件名写入 `public/images/about/`。
- 保留足够分辨率，并移除不必要的相机元数据。

## 2. 建立标准组件

- 在 `src/components/about/` 新建 `LivingLabCard.tsx`。
- 定义场域、图片和本地化文字所需的最小 props。
- 输出照片与文字双栏结构，以及关键词列表插槽。

## 3. 接入关于页

- 为南宝山、金鱼溪和黎波数据补充图片信息。
- 用 `LivingLabCard` 替换轮播中现有的纯文字 article。
- 保留现有轮播导航和文案。

## 4. 样式与响应式

- 为标准卡片添加浅色编辑式双栏布局。
- 桌面保持照片与文字并排，手机折叠为照片优先的单栏。
- 设置统一画幅、对象裁切、边框、间距和最小高度。

## 5. 验证

- 为三张照片补充对应关系测试。
- 运行关于页测试、TypeScript 检查和生产构建。
- 在浏览器中检查桌面与移动页面并修正视觉问题。
