# 首页种子社群桌面单行排版设计

## 目标

调整首页种子社群标题区：第二句“种下一段长期同行的关系，一起走进真实世界。”使用 18px 字号，并在中文桌面端与“成为阿柑少年、家长或伙伴。”处于同一横排。

## 已确认方案

- 新增独立的标题行容器，保留标题与说明文字各自的语义标签。
- 中文桌面端使用不换行的横向布局，并按文字基线对齐。
- 第一句保持现有 48px，第二句调整为 18px。
- 移动端保持上下排列，第二句仍为 18px，避免窄屏溢出。
- 英文文案继续自然换行，避免较长译文在桌面端溢出。
- 其余身份路径、吉祥物、入口和动效保持不变。

## 验证

- 更新首页组件测试，确认标题行容器及中英文布局修饰类存在。
- 运行首页定向测试、应用类型检查和生产构建。
- 在桌面与移动视口检查中文排版、溢出和实际字号。
