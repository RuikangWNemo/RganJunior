# 加入我们：高级折叠信息区设计

## 目标

在不移除现有“少年 / 家长 / 伙伴”种子社群互动舞台的前提下，为 `/join` 增加完整、易判断、易行动的参与信息区。新区域承载“适合谁、当前参与方式、如何加入、常见问题和联系方式”，并延续现有米白纸张、森林绿、阿柑橙与手写字体构成的编辑视觉系统。

## 已确认方向

用户选择保留现有身份互动区，并在其后加入完整折叠内容。页面形成三段式叙事：

1. 米白封面建立品牌主题；
2. 深绿种子社群舞台建立身份认同和情绪连接；
3. 米白折叠信息区帮助家庭判断是否适合、选择参与方式并完成下一步行动。

现有 `/join/apply`、`/join/apply?audience=<id>`、身份路径、角色档案和绿色舞台主 CTA 均保持不变。

## 方案比较

### 方案一：编辑部目录式折叠（采用）

桌面端使用左侧粘性导语与 CTA、右侧编号折叠目录。它与现有编辑特刊风格最一致，也能让长内容保持清晰层级。移动端自然收束为单列。

### 方案二：独立折叠卡片

每一组内容成为圆角卡片，更轻松友好，但容易引入与现有视觉系统不同的通用产品界面感。

### 方案三：时间线路径式长页

内容沿橙色路径依次展开，叙事感强，但会与上方身份路径重复，并显著增加页面长度。

## 信息架构

### 区域标题与导语

- 英文眉题：`WAYS TO JOIN`
- 中文标题：`当前参与方式`
- 核心导语：`走进自然、生活与真实世界`
- 说明阿柑少年面向 12–18 岁青少年及家庭，并保留用户提供的自然、食物、茶、运动、共同生活、真实社区和持续探索表达。
- 左侧提供“提交参与意向”和“预约沟通”两个动作。提交按钮进入 `/join/apply`；预约沟通使用页面内联系方式锚点，避免虚构外部渠道。

### 主折叠章节

使用五个编号章节，同一时间只展开一个：

1. `适合谁`：在同一展开面板内并列呈现“适合愿意”和“不太适合只期待”，通过中性编辑排版表达边界，不使用警告色块。
2. `当前参与方式`：默认展开。展示生活体验营、生活共创营、阿柑少年行动小组、青少年研究与公共议题项目。每项包含时长或开放状态、适合对象和说明。
3. `如何加入`：以 01–04 四步流程呈现提交意向、等待通知、申请持续项目和预约沟通，并在末尾提供两个明确 CTA。
4. `常见问题`：主章节展开后呈现六个轻量二级问答，默认全部收起，避免一次展示大量正文。
5. `联系我们`：展示四川成都蒲江铁牛村麦昆塔社区；微信／电话、邮箱和参与意向表在没有真实值时显示“待更新”，不渲染虚假链接或下划线占位。

### 最终邀请

折叠目录后保留一段简短邀请：先提交参与意向，待合适活动开放后共同判断孩子是否适合加入。重复现有两个动作，不引入第三种转化入口。

## 视觉与交互

- 深绿舞台之后使用米白纸张背景和细分隔线，形成清楚但不突兀的明暗转换。
- 编号、状态和交互重点使用阿柑橙；标题使用现有手写展示字体；正文继续使用站点正文系统。
- 桌面端为约 38% / 62% 的双栏结构，左侧在可用视口内轻度粘性；移动端变为单列，所有内容保持自然文档流。
- 折叠触发器占满一行，包含编号、标题、简短摘要和圆形加号。打开时加号旋转为关闭状态，橙色细线展开。
- 内容高度和透明度使用克制动画；`prefers-reduced-motion` 下取消位移与渐变动画。
- 不新增照片、插画或复杂路径，避免与上方身份舞台竞争。

## 组件与数据组织

- 在 `JoinUs.tsx` 中增加结构化双语内容常量，保持页面内容集中、可测试。
- 抽出页面内的小型 `JoinInfoAccordion`、参与方式行、步骤和 FAQ 渲染函数；如果实现规模明显增大，再移动到 `src/components/join/`，不提前拆分。
- 使用现有 Radix Accordion 基础组件；若项目封装不存在或不适合嵌套 FAQ，则使用原生 `details/summary` 完成二级问答。
- 继续使用 `useLanguage` 和 `pickLocalized`，英文内容需要完整而非机器占位。

## 状态与异常处理

- 默认展开 `当前参与方式`，其余主章节关闭。
- 主折叠使用单选状态，可允许当前项关闭，以便用户获得更简洁的页面视图。
- 页面没有异步数据流；联系方式缺失是内容状态，不是运行时错误。缺失项明确显示“待更新 / To be updated”。
- CTA 仅使用已存在的站内路由或页面锚点，不创建未经确认的电话、邮箱或外部表单链接。

## 可访问性

- 主折叠沿用 Radix 的键盘导航、`aria-expanded`、内容关联和焦点管理。
- 所有触发器达到移动端最小触控高度，焦点环在米白和深绿背景上均清晰可见。
- 状态标签不只依赖颜色表达；图标均为装饰时标记 `aria-hidden`。
- 标题层级从区域 `h2` 到折叠章节 `h3`，FAQ 问题保持可读的语义顺序。

## 验证

- 更新 `JoinUs.test.tsx`：验证完整核心文案、默认打开“当前参与方式”、切换章节、FAQ 二级折叠、CTA 路由、联系锚点和既有身份互动不回归。
- 运行聚焦 Vitest、应用 TypeScript 检查、ESLint、生产构建与 `git diff --check`。
- 在桌面与 390px 移动视口检查页面节奏、粘性布局、折叠动画、焦点状态、横向溢出和控制台错误。
