# Homepage Hero Forest Color Design

## Goal

Align the homepage first screen with the brighter green used by the site's Join surfaces, while preserving the existing editorial layout, mascot, motion, and orange brand accent.

## Approved direction

- Use the existing brand forest green (`--forest`, approximately `#006633`) as the hero background.
- Change the hero subtitle and body copy to the existing warm paper foreground so they remain readable on green.
- Keep the orange wordmark and primary CTA as the visual accent.
- Restyle the secondary CTA with a translucent paper surface and paper-colored border.
- Retune decorative flow lines, nodes, and texture layers so they remain visible without competing with the copy.
- Replace the current paper-colored bottom fade with a forest-to-paper transition into the next section.
- Preserve the current responsive structure, animation behavior, content, and navigation.

## Accessibility and verification

- Maintain strong text/background contrast for title, body copy, and controls.
- Preserve visible hover, active, and focus states.
- Verify desktop and mobile layouts, reduced-motion behavior, build output, and browser console state.
