# 加入我们：暂时移除悬挂吊牌设计

## 目标

在“加入我们”页面暂时停止展示所有悬挂吊牌形态，让绿色区域集中呈现阿柑少年、家长、伙伴的完整连线、阿柑提示语与角色详情入口，同时保留现有吊牌实现，方便之后恢复。

## 方案选择

采用“停止渲染、保留实现”的方案：桌面端 WebGL 吊牌、静态回退吊牌和移动端身份卡都不再出现在页面中；相关组件、素材、配置与样式暂不删除。

未采用的方案：

- 彻底删除吊牌代码与素材：当前需求是“暂时去掉”，删除会增加未来恢复成本。
- 建立完整的运行时功能开关：现阶段只有单页、单状态需求，会引入不必要的配置复杂度。

## 页面行为

- 绿色区域不渲染桌面端吊牌及其静态回退版本。
- 移动端不渲染身份吊牌卡。
- 阿柑少年、家长、伙伴的连续路径与点击入口保持不变。
- 巨大阿柑、循环提示语、角色选择弹窗和申请链接保持不变。
- 吊牌相关实现以一个局部、明确的关闭状态保留，后续可低成本重新启用。

## 验证

- 更新页面测试，确认桌面和移动吊牌容器均不存在。
- 保留角色详情弹窗、角色切换、提示语轮播等既有测试。
- 运行页面测试、完整测试、Lint 与生产构建。
- 在桌面和移动视口检查绿色区域布局，确认移除吊牌后没有空洞、溢出或断裂。
