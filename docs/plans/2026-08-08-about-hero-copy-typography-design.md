# About 首屏文案与标题排版设计

## 目标

精简“关于”页面首屏的信息层级，让新的品牌句先出现，并确保中文主标题中的“阿柑少年”始终独占一行。

## 已确认设计

- 顶部小字由 `About / 关于阿柑少年` 替换为 `把成长放回真实生活里`，原文案和句末标点不保留。
- 顶部小字使用网站现有的中文手写字体，与主标题形成一致但更轻的品牌语气。
- 删除下方重复出现的同一句大号口号。
- 中文主标题保持单个语义化 `h1`，显示为两行：第一行“关于”，第二行“阿柑少年”。
- 英文主标题保持自然文本，不强制套用中文分行规则。
- 主标题的桌面端与移动端字号都比当前版本略小，其他颜色、字体、间距和首屏图片不变。
- 主标题下方的介绍文字参照项目首屏的深绿色层级，使用 About 系统的深森林绿，但保持正文默认字重；字号、行距和字体家族不变。

## 验收

- 中文页面首屏不再出现 `About / 关于阿柑少年`。
- `把成长放回真实生活里` 只出现一次，并以中文手写字体位于主标题上方。
- “阿柑少年”在支持的页面宽度下始终独占一行。
- 首屏介绍文字以深绿色常规字重显示，同时保持原有可读性和换行节奏。
- 中英文页面仍有正确且唯一的一级标题。
