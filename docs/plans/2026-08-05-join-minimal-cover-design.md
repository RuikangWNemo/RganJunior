# 加入我们：极简封面设计

## 目标

简化 `/join` 顶部淡米色封面，移除刊头、期号、边注、解释性文案和绿色区域索引，让用户更快进入身份路径与阿柑互动。

## 确认方案

采用左对齐极简封面。

- 主标题仅保留：`成为阿柑少年`
- 副标题仅保留：`与我们同行`
- 保留封面底部橙色曲线，继续连接绿色区域。
- 保持淡米色与阿柑绿的明暗转场。

删除以下内容：

- `SEED COMMUNITY / JOIN ISSUE 01`
- `种子社群 · 加入我们`
- `成为阿柑少年、家长或伙伴。`
- `从一段真实关系开始，慢慢找到同行的位置。`
- `FIELD NOTE / 001` 及全部边注内容
- `R’GAN JUNIOR / 01—03`
- `COMMUNITY INDEX / ISSUE 01—03`

## 保留范围

- 绿色区域的阿柑少年、家长、伙伴三个身份节点。
- 完整橙色身份曲线及局部描亮交互。
- 阿柑页边批注与三种意图选择。
- 角色档案折页及独立报名页面。
- 已暂停的吊牌状态。

## 响应式与验证

- 桌面端主标题左对齐并保持充足留白。
- 手机端标题稳定换行，不产生额外说明区块。
- 删除绿色索引后同步收紧顶部间距。
- 更新测试，只断言两行核心文案和保留的身份交互。
- 运行完整测试、Lint、生产构建，并检查 1440px 与 390px 视口。
