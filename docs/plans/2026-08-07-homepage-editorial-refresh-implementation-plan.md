# 首页橙绿纪实编辑感改版实施计划

## 范围

只调整首页及其专用内容与样式，不修改导航、现有路由、报名表单、品牌标志或其他页面。

## 实施步骤

1. 更新 Hero 文案、按钮顺序与橙绿文字层级，保留吉祥物、开屏动画和现有左右结构。
2. 新建首页专用双语内容模型，集中维护三条信念、四个项目、真实现场数据和底部行动文案。
3. 用非对称信念布局替换原有三等分卡片。
4. 新建四项项目索引，分别链接现有生活共创营、行动小组和公共议题项目路由。
5. 使用仓库内真实照片建立营地现场图片墙，不生成或伪造活动照片与家长评价。
6. 新建 Nate 发起人故事区块，并链接现有 `/story` 页面。
7. 用深绿色底部邀请区块替换旧种子社群首页区块。
8. 增加首页专用响应式样式和 reduced-motion 处理。
9. 增加首页内容测试，运行类型检查、测试、构建和桌面/移动视觉验证。

## 视觉约束

- 保持浅色米白页面主题，深绿色作为正文与结构色，橙色作为唯一强调色。
- 标题使用现有活泼品牌字体，长正文使用易读中文无衬线字体。
- 卡片采用统一的中等圆角；按钮使用圆角矩形，不使用装饰性胶囊标签。
- 每个主要区块使用不同布局家族，避免连续的等宽卡片和重复左右图文。
- 所有图片声明尺寸或固定比例，减少布局偏移。

## 验证重点

- 首屏 CTA 在常见桌面和移动首屏内可见。
- 中文与英文切换后没有溢出或按钮换行。
- 所有主要链接指向已存在路由。
- 所有新增动画在 reduced-motion 下变为静态。
- 页面新增可见文案不包含长破折号字符。
