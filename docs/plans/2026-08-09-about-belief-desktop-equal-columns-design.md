# 关于页“我们相信”桌面端等宽布局设计

## 目标

让关于页“我们相信”轮播中的照片在桌面端更突出，并使照片与文字区域严格保持 1:1 的宽度关系。

## 设计

- 将桌面端轮播条目的两列网格由 `0.9fr / 1.1fr` 调整为 `1fr / 1fr`。
- 沿用当前栏间距、照片 4:3 比例、裁切方式和内容结构，避免引入额外视觉变化。
- 仅调整宽度不小于 1024px 的基础桌面规则；保留 768–1023px 的平板比例和小于 768px 的单列移动端布局。

## 验证

- 通过样式断言确认桌面基础规则使用等宽两列。
- 运行关于页相关测试，确认轮播内容与交互不受影响。
- 在桌面视口检查照片和文字各占可用网格空间的一半，并确认移动端仍为单列。
