# 首页种子社群三级字体设计

## 目标

将首页“成为阿柑少年、家长或伙伴”板块从五档零散字号收敛为与首页其他章节一致的 48px / 36px / 18px 三级系统。

## 已确认方案

- 第一级：“成为阿柑少年、家长或伙伴。”使用 48px 橙色手写体。
- 第二级：“种下一段长期同行的关系，一起走进真实世界。”使用 36px 暖米白手写体。
- 第三级：“种子社群”、阿柑少年/家长/伙伴三个身份和“进入加入入口”统一使用 18px 普通字体。
- “种子社群”使用浅桃色，身份和入口使用暖米白；颜色差异不增加新的字号层级。
- 保留现有森林绿背景、身份路径、吉祥物、入口结构和动效，不修改内容或交互逻辑。
- 移动端两档手写字体自适应缩小，18px辅助信息保持不变。
- 中英文共享相同视觉角色，允许英文因长度产生不同的自然行数。

## 验证

- 更新首页测试，确认主标题、引导句、三个身份和入口使用对应语义类。
- 运行首页定向测试、应用类型检查、生产构建和相关 TSX ESLint。
- 在桌面与移动视口检查中英文标题行数、身份标签位置、溢出和实际字号。
