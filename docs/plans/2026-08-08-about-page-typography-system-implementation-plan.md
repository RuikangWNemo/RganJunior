# 关于页面三级字体系统实施计划

## 范围

仅调整 `src/index.css` 中 `.about-v2-page` 作用域内的排版。保留 `src/pages/About.tsx` 的语义结构、内容和交互。

## 实施步骤

1. 在关于页作用域增加统一字体尺寸令牌：一级 48px、二级 36px、正文 18px，并提供移动端下限。
2. 将首屏与章节 `h1/h2` 统一映射到一级标题。
3. 将团队、主张、轮播内容和场域名称等 `h3/h4/h5` 映射到二级标题。
4. 将介绍、故事、理念、方法和场域正文统一映射到正文层级。
5. 根据浅色和深绿色背景分别应用深绿、橙色和暖白色，并保留辅助信息的小字号层级。
6. 增加必要的响应式覆盖，避免旧的移动端规则重新放大标题。
7. 运行测试与构建，并在桌面和移动视口检查渲染结果。

## 不修改

- 页面文案和国际化内容
- 图片、卡片布局和轮播逻辑
- 页面导航、路由和滚动行为
- 首页及其他页面的排版规则
