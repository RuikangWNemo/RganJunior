# 家长守护团展示设计

## 目标

在“关于我们”的“我们的团队”章节末尾加入独立的“家长守护团”，让访问者清楚了解家长可以参与项目共创、支持活动开展，并为后续公开成员资料预留位置。

## 页面结构

- 位于“成人支持团队｜麦昆塔教育”之后，作为团队列表中的第 04 组。
- 组名为“家长守护团 / Parent Guardian Circle”。
- 先用一块说明区域介绍家长守护团的角色，再展示成员头像占位卡片。
- 预留 4 张成员头像卡片；桌面端四列，移动端两列。

## 内容与视觉

- 说明文案强调两个参与方向：加入项目与内容共创、支持线下活动与家庭连接。
- 延续现有 About 页的橙色章节标题、森林绿说明卡、纸张色背景和圆角卡片语言。
- 头像占位符使用中性的内建图形，不依赖尚未提供的图片资源。
- 每张卡片显示“姓名待补充 / Name to be added”和“角色待补充 / Role to be added”，便于后续直接替换真实资料。

## 可访问性与响应式

- 为组标题、成员名录和每张占位卡提供中英文可访问名称。
- 占位图形视为装饰，不重复朗读无意义信息。
- 保持现有断点：桌面四列、手机两列，不增加横向滚动。

## 验证

- 更新 About 页面测试，验证团队组顺序、家长守护团文案和 4 张占位卡。
- 运行 About 页面定向测试、应用类型检查和生产构建。
- 在桌面与移动视口检查新增区块的布局和阅读顺序。
