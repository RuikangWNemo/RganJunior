# 关于页面三级字体系统设计

## 目标

以首页“最近，我们一起生活了5天4夜”的编辑式字体设计为基准，统一完整“关于”页面的中文与英文字体层级。调整只涉及排版与文字颜色，不改变现有内容、图片、区块结构、轮播交互和导航行为。

## 设计方向

采用严格的三级内容字体体系：

1. 一级标题：桌面端 48px，橙色，品牌手写体，用于页面主标题和四个章节标题。
2. 二级标题：桌面端 36px，品牌手写体，用于团队分组标题、内容主张、卡片标题和场域名称。浅色背景优先使用橙色或深绿色；深绿色背景使用橙色或暖白色，以实际对比度为准。
3. 三级正文：桌面端 18px，正常无衬线字体。浅色背景使用深绿色，深色背景使用暖白色。

编号、眉题、导航、身份、地点、关键词和图片说明属于辅助信息，不强行放大为正文，维持 14–16px 的正常字体，以保护三级内容层级。

## 响应式规则

- 桌面端以 48px / 36px / 18px 为明确上限和基准。
- 移动端通过 `clamp()` 缩放到约 40px / 30px / 17px，避免长标题溢出或出现破碎换行。
- 手写标题保持紧凑行高；正文保持舒展行高和可读段落宽度。

## 颜色规则

- 橙色：沿用关于页当前品牌橙 `#ff6a1f`。
- 深绿色：沿用关于页森林绿 `#063f30`。
- 暖白色：沿用关于页纸张色 `#f4efe3`。
- 浅色区域正文使用深绿色；深绿色区域正文使用暖白色。
- 避免低对比度的半透明灰色正文，确保 18px 正文清晰稳定。

## 应用范围

覆盖关于页首屏、团队介绍、发起人、青少年伙伴、成人支持团队、共创方向、理念、方法和真实场域。现有辅助标签和交互控件只校准字体家族、行高及颜色，不改变其信息等级。

## 验证

- 在桌面与移动视口检查四个章节及其轮播内容。
- 确认一级、二级、正文三种层级可一眼区分。
- 确认深色卡片的标题和正文对比度充足。
- 运行项目测试与生产构建，确认没有结构或交互回归。
