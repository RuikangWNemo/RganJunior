# 首页电影式开场实施计划

## 1. 准备专用媒体

- 复用现有约 15 秒的 `home-scroll-video.mp4`，保持完整叙事和原始播放速度。
- 导出首帧和尾帧 WebP，用于加载占位、文字背景和减少动态效果模式。
- 用 `ffprobe` 核对时长、尺寸、编码和文件体积。

## 2. 实现回访状态

- 用带版本号的 JSON 状态取代旧的纯版本字符串。
- 根据最后一次首页访问时间判断 7 天未访问；7 天内回访刷新访问时间。
- 只在完成、主动跳过或降级文字完成后记录开场完成时间。
- 为首次访问、活跃回访、超期回访、旧格式和版本变化增加单元测试。

## 3. 重建开场组件

- 将现有吉祥物纸张开屏替换为视频、视频渐隐、宣言浮现和退出四个阶段。
- 使用原生视频事件处理可播放、播放结束和错误状态，并设置加载超时降级。
- 在组件生命周期内锁定并恢复页面滚动。
- 动效只使用 `opacity` 与 `transform`，大面积背景不动画模糊或滤镜。
- 支持跳过按钮、中英文文字和 `prefers-reduced-motion`。

## 4. 调整首页结构

- 从首页正文移除 `HomeScrollVideo` 挂载，保留现有 Hero 和后续内容顺序。
- 将新的访问状态接入 `HeroMascotStage`，保证开场退出时吉祥物 Hero 自然显现。

## 5. 验证与调优

- 运行单元测试、Lint 和生产构建。
- 启动开发服务器，在桌面和 390px 移动端验证首次播放与回访直达。
- 检查视频首帧、尾帧文字、跳过、加载失败模拟、减少动态效果和滚动恢复。
- 根据实际画面微调裁切、文字宽度、停留时间和转场曲线。
