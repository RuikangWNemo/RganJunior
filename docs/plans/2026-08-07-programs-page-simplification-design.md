# 项目页简化与路由迁移设计

## 目标

将现有行动页进一步收敛为直接、清晰的产品页面。删除 Nate 人物首屏和三产品概览，让用户进入页面后立即阅读第一个产品，并依次了解另外两个产品。

## 命名与路由

- 主导航“行动”改为“项目”，英文从 `Action` 改为 `Programs`。
- 主路由从 `/actions` 迁移到 `/programs`。
- 意向页从 `/actions/inquiry` 迁移到 `/programs/inquiry`。
- 所有站内项目链接、SEO 元信息与站点地图同步使用新路由。
- 旧 `/actions` 与 `/actions/inquiry` 保留自动跳转，并继续携带原有锚点和查询参数。
- “阿柑少年行动小组”等产品正式名称中的“行动”不修改。

## 导航

“项目”保留桌面下拉菜单与手机嵌套菜单。次级菜单只显示三个产品名称：

- 生活共创营
- 阿柑少年行动小组
- 研究与公共议题项目

删除每个菜单项下的副标题和说明，让菜单更短、更容易扫读。次级菜单的可访问名称同步改为“项目次级菜单 / Programs submenu”。

## 页面删减

完整删除以下内容：

- Nate 人物首屏
- Nate 肖像与图片说明
- Nate 第一人称邀请文案
- 首屏“查看三种行动”和“直接咨询”按钮
- “从一次相遇，到持续行动”标题与说明
- 三个产品概览链接列表

## 页面结构

页面不增加新的营销首屏或目录。导航下方直接进入“生活共创营”，随后依次展示：

1. 生活共创营
2. 阿柑少年行动小组
3. 研究与公共议题项目

视觉上不显示额外的页面封面。使用无视觉占位的页面主标题“项目 / Programs”保持文档语义完整，三个产品名称继续作为章节标题。

三个产品内部已有的对象、周期、内容、安全、费用、真实照片、状态、直接咨询和参与意向入口继续保留。

## 意向与联系方式

独立意向表单、接口和联系方式逻辑不变，仅迁移页面地址、返回链接、提交来源路径和生成的项目链接。电话、微信和邮箱仍从集中配置读取。

## 验证

- 验证导航显示“项目 / Programs”。
- 验证桌面和手机次级菜单只显示三个产品名称。
- 验证 `/programs` 和三个产品锚点。
- 验证 `/programs/inquiry` 的产品预选与返回链接。
- 验证旧路由携带锚点和查询参数跳转到新路由。
- 验证站内不存在仍指向旧项目路由的主入口。
- 运行全量测试、Lint 和生产构建。
- 在桌面和 390px 手机视口检查首个产品能直接进入视野、页面无横向溢出。
