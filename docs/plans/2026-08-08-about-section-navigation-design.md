# 关于页章节导航与色块结构设计

## 目标

提升“关于”页面的信息结构和长文可读性，让页面内的章节子菜单与“项目”页面使用同一套字体、颜色和选中状态，同时用克制的背景色块区分四个章节。

## 方案比较

1. 只给章节标题增加色块。改动最轻，但不足以改善长页面的章节边界。
2. 让章节导航与“项目”页同构，并为四个完整章节使用交替背景色块。结构清楚、视觉连续，且不需要改动内容或路由。
3. 把每个内容模块都改成独立彩色卡片。区分度最高，但会切碎叙事并增加视觉噪音。

## 已确认设计

采用方案 2，范围只包括“关于”页面内部，不修改顶部主导航的“关于”下拉菜单。

- 将“项目”页章节导航抽为 `EditorialSectionNav` 共享组件；“项目”和“关于”使用同一份 DOM、动画与 CSS，只传入各自的菜单数据和点击回调。
- 共享章节子菜单使用普通无衬线字体、暖纸色背景、森林绿弱化文字和橙色激活状态，不保留“关于”页专属菜单样式。
- 保留四个现有锚点、滚动联动、URL hash 和移动端横向滚动。
- “我们的团队”“我们相信”“我们的方法”“空间与场域”使用暖纸色、浅杏色、淡绿色和深一层纸色作为完整章节背景。
- Nate 介绍等正文统一使用 `Noto Sans SC` / 系统无衬线字体；标题仍保留品牌手写字体。
- 当前激活章节与“项目”页一致，使用橙色文字、加粗字重与底部激活线。

## 验证

- 检查四个锚点在滚动与点击时仍能正确激活。
- 检查桌面与手机尺寸下的吸顶位置、横向滚动和文字可读性。
- 运行关于页测试、应用类型检查和生产构建。

## 后续色块层级优化

共享吸顶菜单保持“项目”页的暖纸色。About 首章改用“项目”首个内容章节的浅杏橙色，第二章回到暖纸色，后续使用淡绿色和深一层米色，形成“导航暖纸色 → 首章浅杏橙 → 第二章暖纸色 → 第三章淡绿 → 第四章深米色”的清晰分段。章节眉题文字继续沿用原有森林绿色，不为这次背景问题引入额外的文字颜色规则。
