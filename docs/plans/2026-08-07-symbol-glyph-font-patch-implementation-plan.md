# 异常图案汉字定向字体补丁实施计划

1. 从用户已有的 TanukiMagic 原始 TTF 重新生成网站子集，保留现有西文字符、“一、信”，并加入“心、方、音、日、月”。
2. 从用户已有的清松手写体生成只包含简体“圆”的最小字体子集。
3. 在 `src/index.css` 中扩展 TanukiMagic 的 `unicode-range`，声明“圆”字形补丁，并把补丁字体接入现有全局字体变量。
4. 用字体整形工具核对目标字符的最终映射，用构建产物确认字体资源可访问。
5. 运行相关测试、Lint、类型检查与生产构建，并在桌面及手机浏览器检查标题、姓名、导航和文章正文中的目标字形。
