## 本地环境说明及验证边界

初次检查发现，当前工作区的两项公开 Supabase 浏览器配置为空，原有文章页因此报加载错误。最终验证复用了本机既有、对应同一项目的发布产物中的公开 URL 与 publishable key，只注入当前本地构建进程，没有修改 `.env` 文件、使用服务端 Secret 或调整远端配置。公开与服务端密钥的边界参见 [Supabase API Keys 官方说明](https://supabase.com/docs/guides/getting-started/api-keys)。

本地静态预览不提供 `/api/analytics/collect`，因此浏览器保留访问统计接口的 404 与页面离开时的请求中止记录。页面静态资源和文章页面渲染已分别检查，不能把该接口缺失写成控制台零错误。访问统计服务端行为不属于本次本地前端验收。

本次不宣称完整后台业务验证或所有功能均已覆盖。新增采访、营后跟进、累计活动台账、去重家庭数和持续参与规则仍按提案后续补充。
