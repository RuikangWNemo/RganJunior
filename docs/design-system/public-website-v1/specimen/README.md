# Designer Specimen

这是 `Public Website Design Direction v1` 的隔离式设计评审网站，不属于公开网站路由，也不修改现有页面或 legacy CSS。

## 查看

在项目现有 Vite 开发服务器运行时打开：

```text
/docs/design-system/public-website-v1/specimen/
```

## 评审范围

- 视觉方向与反目标
- Typography、Color、Spacing
- Editorial Manifesto
- Alternating Media Story
- Feature + Secondary
- Desktop 1440、iPad 820、Mobile 390
- Grid overlay
- Content-preserving migration contract

## 冻结规则

只有设计团队确认三种标准模块在三个关键画幅中都成立，候选 tokens 才能标记为 v1 Frozen，并开始 Programs 的渐进迁移。
