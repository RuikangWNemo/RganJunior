01 / Direction

我们要建立的，
不是另一套网页风格。

它是一套在内容变化、页面增加和团队协作之后，仍然能够保持阿柑少年气质的判断方法。

01

真实照片先于 UI

Photography is primary content, not decoration. 设计先给人物、土地和行动足够尺度，再考虑界面。

02

手写负责情绪

短标题、短引语和品牌句使用手写字体；正文、数据、导航和时间地点使用清晰的信息字体。

03

一个 Section 一个主角

每个区域必须明确 Primary、Secondary 与 Supporting information，不让所有内容同时喊叫。

04

编辑构图，不是卡片网格

通过照片、文字、留白、分隔线和色块建立层级；card 只用于真正独立或可操作的对象。

NOT THIS

  • 儿童卡通网站
  • 传统 NGO 模板
  • 商业 SaaS 页面
  • 冷淡奢侈品牌
  • 过度手账拼贴

03 / Modules

全站 70% 的内容，
从三种组合开始。

模块固定内容关系，不固定每个页面的视觉表现。真实内容永远比 demo 对称更重要。

A

Editorial Manifesto

短手写标题、Lead、大幅照片和正文。低密度，建立页面立场。

SectionHeader + ImageFrame + Body
B

Alternating Media Story

照片占 50–60%，文字占 40–50%；允许左右交替，不制造普通 card。

MediaTextBlock
C

Feature + Secondary

一个主要故事配一个辅助故事，以尺度和信息量建立清晰主次。

FeatureStory

04 / Live Specimen

在真实画幅里判断。

切换 Desktop、iPad 与 Mobile，检查标题比例、照片尺度、模块重排和页面密度。

05 / Migration

新系统旁路生长，
旧页面逐步退休。

  1. 01
    Content Snapshot

    先冻结文案、图片、顺序、链接、路由、数据和 existing IDs。

  2. 02
    Foundations

    只替换 typography、color 和 spacing roles。

  3. 03
    Modules

    以 Section、ImageFrame、MediaTextBlock 等逐项替换。

  4. 04
    Regression

    完成内容、视觉、Tablet、可访问性和 reduced-motion 检查。

  5. 05
    Retire Legacy

    只删除已经确认无引用的 selectors，不进行全局大扫除。
